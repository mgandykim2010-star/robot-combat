로봇 설계실

클래스와 부품을 고르고, 물리·공학 공식을 직접 계산해 로봇을 5단계까지 강화하세요. SURVIVAL SHOWDOWN과 플레이어가 팀을 직접 선택하는 5대5 BASE DESTRUCTION을 지원합니다.

로봇 선택

부품 조립 (개발실)

업그레이드 실험 (공식을 직접 계산해 오차 범위 안에 들어오면 다음 단계 · 단계마다 1단계 수치의 +5%씩 단리 · 오답 시 3분 잠금 · 단계가 오를수록 문제가 어려워짐)

능력치

공학 계산 (단순화 모델)

조작

WASD/방향키 이동 · 마우스로 방향 조준(조준선 표시) · 좌클릭 공격 · 우클릭 근거리/원거리 전환 · Space 궁극기(누르는 동안 조준선, 떼면 발사) · Shift 부스트(최대 배터리 10% 소모) · Q 또는 Ctrl 방전(보호막 무시 고정 피해) · Esc 전투 종료. Ctrl+W는 브라우저 탭을 닫으므로 이동 중에는 Q 사용을 권장합니다.
모바일 화면 왼쪽을 끌면 이동, 오른쪽을 끌면 조준·사격, 오른쪽 아래 버튼으로 공격·궁극기·부스트·방전·모드 전환. 궁극기 버튼은 누르는 동안 조준선이 보이고 손을 떼면 발사됩니다. 조준하지 않고 이동만 하면 로봇이 이동 방향을 바라봅니다.

기획서 대비 구현 범위

구현 완료 — 4개 클래스와 공격/궁극기, 설계실 부품 조립과 공학 계산, 업그레이드 5단계(물리 문제 풀이), 배터리·에너지·보호막 자원 분리, 부스트·방전, SURVIVAL SHOWDOWN(자기장·충전소·건전지), AI 상대, PC와 모바일 입력.
BASE DESTRUCTION — 5대5 단일 공격로 팀전, 미니언 자동 진격, 포탑 자동 방어, 적 기지 파괴 승리 및 8초 후 부활을 구현했습니다. 친구 방에서는 최대 10명이 접속하고, 부족한 인원은 AI로 채웁니다. 구조물 체력·미니언 피해량은 밸런스 테스트용 초기값입니다. 3D(Three.js): 기획서는 쿼터뷰 3D를 권장했으나, 제한된 기간에 전투 로직과 공학 계산을 먼저 검증하려고 2D 탑다운으로 만들었습니다. 시점과 조작 구조는 그대로 두었으므로 렌더링만 교체하면 됩니다.
기획서에서 바꾼 것 — 어쌔신 에너지 소모 8→10: 기획서 수치 그대로면 어쌔신만 에너지가 남아돌아 "자원 판단" 원칙이 깨져서 조정했습니다. 원거리 피해 배율도 클래스 간 초당 피해 격차가 4.5배라 1.5배로 좁혔습니다. 그 외 능력치 32칸은 기획서 3장 표와 모두 같습니다.
